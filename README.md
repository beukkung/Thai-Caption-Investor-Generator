# Thai Caption Money Lab

A mass-friendly Thai caption generator for money, work, investing, and everyday financial life.

## Product direction

The original project was an LSTM text-generation experiment trained on investor quotes. This revamp turns it into a lightweight consumer product that is understandable in seconds and useful beyond active investors.

### Who it is for
- Salary workers
- Beginner investors
- People saving money
- Finance-content creators
- Anyone who wants a funny, sharp, or relatable Thai caption about money

### Core UX
1. Pick a topic
2. Pick a tone
3. Add optional context
4. Generate
5. Copy or share

### Categories
- เงินเดือนออก
- มนุษย์เงินเดือน
- ออมเงิน
- ลงทุน
- ตลาดเขียว
- ตลาดแดง
- ใช้เงิน
- สายฮา

## Run locally

Open index.html directly in a browser. No backend, account, database, or build step is required.

## Legacy assets

The original notebook, corpus, tokenizer, and LSTM model remain in the repository as historical experiment assets.
